# 📧 Gmail Spam Classifier

## 📌 Mô tả
Dự án Machine Learning phân loại email Spam vs Ham.

## ⚙️ Công nghệ
- Python
- Scikit-learn
- TF-IDF
- Streamlit

## 🚀 Cách chạy

### 1. Cài thư viện
pip install -r requirements.txt

### 2. Train model
python run.py

### 3. Chạy web
streamlit run streamlit_app.py

## 📊 Models
- Naive Bayes
- SVM
- Random Forest
